🛗 Elevator Game

Detta projekt är ett enkelt spel skrivet i Java.

Spelet handlar om att spelaren åker hiss och möter olika personer beroende på vilken våning som väljs.
Bakgrunden till spelet är att spelaren har fått ett nytt jobb och målet är att ta sig hela vägen upp till 100:e våningen.

Projektet är inte helt färdigt ännu och kommer att byggas ut med fler händelser och möten på olika våningar.
